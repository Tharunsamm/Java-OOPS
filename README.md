# ☕ Java Programming Assessments

A collection of Java programming exercises and assessments focused on strengthening my understanding of **Core Java, Object-Oriented Programming (OOP), problem-solving, and application development fundamentals**.

This repository documents my hands-on practice with Java concepts through progressively structured programming exercises.

---

## 📌 About This Repository

The programs in this repository are designed to apply Java concepts through practical examples. Each assessment focuses on different areas of Java, ranging from fundamental programming concepts to Object-Oriented Programming.

The primary goal of this repository is to build a strong foundation in Java by implementing concepts through code rather than only studying them theoretically.

---

## 📂 Assessments

### 🔹 Objects & Constructors

This assessment focuses on understanding how Java classes and objects are created and how constructors and methods are used to initialize and manage object data.

**Concepts practiced:**

* Classes and Objects
* Constructors
* Instance Variables
* Methods
* Getter and Setter Methods
* Object Initialization
* `this` keyword
* ArrayList and Collections
* Basic Object-Oriented Design

Examples include programs involving:

* Person
* Dog
* Employee
* Student
* Bank Account
* Library
* Inventory
* School
* Restaurant
* Travel Booking

---

### 🔹 Inheritance & Method Overriding

This assessment focuses on Java inheritance and how child classes can inherit and customize the behavior of parent classes.

**Concepts practiced:**

* Inheritance
* Parent and Child Classes
* `extends` keyword
* Method Overriding
* `@Override` annotation
* `super` keyword
* Hierarchical Inheritance
* Runtime Polymorphism
* Class Hierarchies

Examples include:

* Animal → Dog / Cat
* Vehicle → Car / Truck / Motorcycle
* Shape → Rectangle / Circle
* Employee → Manager / Developer / Programmer
* BankAccount → SavingsAccount

## 🚀 Running the Programs

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Navigate to the repository

```bash
cd <repository-name>
```

### 3. Navigate to an assessment folder

For example:

```bash
cd Inheritance
```

### 4. Compile the Java program

```bash
javac q1.java
```

### 5. Run the program

```bash
java q1
```

Replace `q1` with the name of the Java file you want to execute.
